# راهنمای دیتاست

## منبع اولیه
حدود یک میلیون آگهی ملکی دیوار بنا بر اعلام کاربر در اختیار پروژه است.

## ارزش مورد انتظار
- کشف واژگان رسمی و محاوره‌ای مردم و مشاوران.
- استخراج مترادف‌ها و شکل‌های نوشتاری متفاوت.
- شناسایی الگوهای بیان متراژ، قیمت، تعداد اتاق و سایر ویژگی‌ها.
- شناسایی عبارات مربوط به نوع معامله و ویژگی‌های مکانی/ساختمانی.
- ساخت مجموعه نمونه برای برچسب‌گذاری و ارزیابی موتور استخراج.

## محدودیت‌ها
- متن آگهی لزوماً دقیق یا قابل راستی‌آزمایی نیست.
- یک آگهی ممکن است چند عدد با معناهای متفاوت داشته باشد؛ مانند زمین، بنا، قیمت کل و قیمت هر متر.
- زبان آگهی با زبان مکالمه مشتری یکسان نیست.
- داده ممکن است تکراری، ناقص، قدیمی یا دارای اطلاعات شخصی باشد.
- پیش از پردازش یا انتشار، شرایط مجاز استفاده از داده و حریم خصوصی باید بررسی شود.

## سیاست نگهداری
- دیتاست خام را در Git commit نکنید.
- فایل‌های بزرگ داده در مخزن کد قرار نگیرند.
- داده‌های نمونه برای تست باید کوچک، پاک‌سازی‌شده و مجاز باشند.
- متن خام، متن نرمال‌شده و برچسب تأییدشده باید از هم قابل تفکیک باشند.
- هیچ شماره تلفن، نام شخص، نشانی دقیق یا شناسه حساس نباید وارد نمونه‌های عمومی مخزن شود.

## وضعیت فعلی
قالب فایل‌ها، نام فیلدها، encoding، پوشش مکانی و کیفیت داده هنوز بررسی نشده است.
