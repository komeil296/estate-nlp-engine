این اعداد accuracy/precision/recall طلایی نیستند. برچسب ساختاریافته ممکن است در متن تکرار نشده باشد یا با متن اختلاف داشته باشد. برای ادعای کیفیت باید مجموعه طلایی انسانی ساخته شود.

### ابزارهای تکرارپذیر

- `scripts/audit_divar_sqlite.py`: ممیزی read-only ساختار و توزیع فیلدها؛ خروجی aggregate و بدون نمایش متن آگهی.
- `scripts/evaluate_divar_extractor.py`: ارزیابی توافق weak-label روی نمونه طبقه‌بندی‌شده؛ متن آگهی را چاپ یا ذخیره نمی‌کند.

### مرحله بعد

1. ساخت مجموعه طلایی کوچک و دستی برای transaction، property type، area، rooms و financial mentions.
2. بررسی خطاهای transaction در presell/partnership و اجاره موقت بدون اجبار برچسب منبع.
3. توسعه Schema برای ویژگی‌های چندحالته گرمایش/سرمایش/سرویس و سال/طبقه بازه‌ای.
4. طراحی parser مستقل اعداد نوشتاری و نگاشت واحدهای مالی فقط با شواهد.
5. ساخت pipeline weak-label export با تفکیک train/validation/test و جلوگیری از نشت رکوردهای یکسان.
