# Financial Visibility Audit — Technical Note

هدف این مرحله تشخیص منشأ اختلاف بین مقادیر مالی ساختاریافته و متن آگهی است.

این ابزار چهار نوع شاهد را جدا می‌کند:
1. عدد خام برابر با مقدار منبع
2. عبارت عددی با مقیاس صریح برابر با مقدار منبع
3. نسبت‌های مقیاسی احتمالی که صرفاً برای بررسی انسانی‌اند
4. وجود یا نبود نشانه مالی و نشانه نقش مورد انتظار

این ابزار ادعا نمی‌کند که ستون‌های SQLite برچسب طلایی هستند. ممکن است مبلغ در رابط آگهی یا فیلد ساختاریافته بوده باشد و در توضیحات متنی تکرار نشده باشد. در چنین وضعیتی، نبود مبلغ در متن، خطای NLP محسوب نمی‌شود.

هیچ متن خام یا evidence در گزارش ذخیره نمی‌شود. دیتابیس فقط‌خواندنی است.
