# Estate NLP Engine

موتور پردازش زبان فارسی در حوزه املاک

## هدف پروژه
ساخت یک موتور مستقل، سریع و قابل اجرای آفلاین برای تحلیل متن‌های فارسی مرتبط با املاک؛ با تمرکز اولیه بر استخراج واژگان، عبارت‌ها و ویژگی‌های ساختاریافته از آگهی‌های ملکی و سپس متن‌های طبیعی مشاوران و مشتریان.

این پروژه بخشی از زیرساخت یک CRM هوشمند و موبایل‌محور برای مشاورین املاک است. در نسخه نخست، هدف ساخت موتور قواعدمحور است؛ نه آموزش یا اجرای یک مدل زبانی بزرگ.

## اصول فعلی
- اول استخراج آفلاین و قواعد شفاف؛ بعداً بررسی مدل‌های یادگیری ماشین.
- جداسازی متن خام، متن نرمال‌شده، خروجی استخراج و داده تأییدشده.
- هیچ داده واقعی آگهی یا اطلاعات شخصی نباید بدون بررسی مجوز و حریم خصوصی وارد مخزن Git شود.
- هر مرحله باید همراه با تست و به‌روزرسانی مستندات باشد.
- تصمیم‌های قطعی از ایده‌ها و پیشنهادهای آزمایشی جدا نگه داشته شوند.

## وضعیت فعلی
مرحله صفر: ایجاد مخزن و مستندات پایه. هنوز کد اجرایی، دیتاست نمونه یا موتور استخراج پیاده‌سازی نشده است.
